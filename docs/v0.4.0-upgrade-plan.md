  export function layoutToDocModel(parseJson, opts) {...}
  // docModel → content_list JSON 字符串（MinerU 对齐：[{page,type,text|rows,bbox,level?}]）

- `lib/export.js`：`EXTS` 加 `content-list: ".json"`、`"pdf-replica": ".pdf"`；`saveResult` 新分支 `content-list`：有 layoutJson → layoutToDocModel → 落盘；无 → `markdownToBlocks` 降级（bbox=null）+ note「无版面坐标，content-list 不含 bbox」。

#### 3.3 复刻度评分（A3）

**目标**：「完美」可度量。数字 PDF 用原件做 ground truth，量化每次改动的复刻水平。
- **新增** `lib/fidelity.js`：
  ```js
  // sourcePath(本地 pdf) + docModel(含 bbox) → { textCoverage, blockIoU, pageMatch, overall, detail }
  // pymupdf 脚本（spawnPdfScript 同款）逐页输出：词序列、块矩形(x0,y0,x1,y1,pageW,pageH)、页数

  // pageMatch：页数一致 + 每页方向一致（有页尺寸数据时含尺寸±2% 一致）
  // overall：0.5×textCoverage + 0.3×blockIoU + 0.2×pageMatch（权重常量可调）
  export async function scoreReplica({ sourcePath, docModel, pythonTimeoutMs }) {...}
  ```
- 接入：`finishResult()`——`format === "content-list"` 且 sourcePath 为本地 pdf 时评分，note 追加 `复刻度评分：overall 87.3（文本 92.1 / 版面 85.0 / 页面 100）`。
- **测试**（~8 例）：合成 PDF（pymupdf 生成，缺依赖跳过）+ 已知 docModel → 断言分数区间；抽样逻辑；缺 python 返回 null 不阻断。**3–4 人日**。

### Wave C：几何与样式保真

#### 3.8 docx 页面几何钉死（C1）

- 页尺寸来源（优先级）：① `layoutJson.pages[i]` 自带 width/height（§8.1 实测如有）；② `hq.pdfPath` 本地源时 pymupdf 读 `page.rect`（pt）。
- `lib/ooxml.js` `sectPrXml`（L344）加 `pageSize` 参数：`<w:pgSz w:w="${wTwips}" w:h="${hTwips}" .../>`（twips=pt×20）；orientation 改由 `w>h` 判定（backend isLandscape 作无尺寸时的回退）；margins 先保持现值（C2 之后再评估 bbox 推边距）。
- `blocksToDocxPages(pages, {..., pageSizes})`；pipeline `finishResult` 组装 pageSizes（与 hq 同源取 pdfPath）传入。
- **测试 5 例**：非 A4 尺寸 fixture（pymupdf 生成 420×594pt 文档）→ 解包产物 docx 断言 pgSz；无尺寸回退 A4；横竖向。**1.5–2 人日**。

#### 3.9 字号/行距传递（C2）

- `lib/layout.js`：正文块（p/text）估计 `fontSize`（mm→pt 由页高换算）：`estimatedLines = 显式换行数 + wrap 估算(字符宽≈0.5×行高)`，`fontSize ≈ clamp(position.h / estimatedLines / 页高×页高pt, 7, 26)`；估计失败（极端比例）→ 无 fontSize 走预设。行距：段落内相邻行 y 差均值 → `lineSpacing`（倍数）。
- `html.js` `blocksToHtml`：块有 fontSize 时内联 `style="font-size:${pt}pt"`（既有 scale 乘子继续生效）；`ooxml.js` run 的 `w:sz` 用估计值 half-points。
- 配置 `fontSizeFromLayout` 默认 true。**依赖 3.8**（页高 pt）。
- **测试 6 例**：fixture 标题/正文/小字号图注的估计值区间；失败回退预设；golden 快照随之刷新一次。**2–3 人日**。

#### 3.10 sandwich PDF（C3，扫描件复刻旗舰）

- **新增** `lib/replica.js`：`replicaPdf({ sourcePath, docModel, dpi })`——pymupdf 脚本：逐页 `get_pixmap(dpi)` → 新文档 `insert_image(rect, pixmap)` 全页打底；仅对**文本类块**（title/paragraph/text，含标题）按 `bbox×页面pt` 反算 rect，`insert_textbox(rect, text, fontname="china-s", fontsize=min(9, rect高/行数), render_mode=3)` 隐形叠加；表格/图片/公式区域跳过（位图里已存在）。返回 Buffer。超长文本自动缩字号/截断保护（insert_textbox 返回负值时降 fontsize 重试一次）。
- `saveResult` 分支 `"pdf-replica"`：要求本地 pdf + layoutJson，否则降级现有 pdf 路径 + note「复刻模式需本地 PDF 与版面数据，已按可读 PDF 输出」。数字 PDF 全文本层时 note「原件即复刻，可直接使用原文件」。
- `index.js` FORMATS 加 `"pdf-replica"`；命令 `--pdf-replica`；配置 `replicaDpi` 默认 200。
- **测试 6 例**：pymupdf 生成含文本页 → 产物可打开、页数一致、隐形文本可提取（get_text 命中原文）；无 layout 降级；图片页不叠加。**2–3 人日**。

### Wave D：能力扩展

#### 3.15 fallback 自动化（D1）

#### 3.16 tier/effort 档位化（D2）

- `pipeline.js` 新增纯函数 `resolveTier(tier, kind, cfg)` → `{engine, format?, hqForce?}`：`flash`=PDF 文本层直取优先（薄页走 general 补页，见 3.5b）/图片 general；`basic`=accurate；`standard`=vl；`advanced`=vl+强制 hq+预设 docx；`auto`（默认）=现有路由不变。映射结果仍走 `resolveRoute`。
- 工具 schema 加可选 `tier`（enum）与 `effort`（low/high）；description 经验法则改「优先 tier」。`effort=low`：vlSegmentPages×2、hq 关、vlPollTimeoutMs 减半（recognize 内应用，不改配置文件）。
- 命令：`--flash/--basic/--standard/--advanced`、`--effort low|high`；配置 `defaultTier` 默认 auto；面板下拉。
- **测试 8 例**：tier×kind 矩阵、显式 engine 优先于 tier、cmd-e2e 扩展。**2 人日**。

#### 3.17 分段流式落盘（D3）

`recognizeSegmented`：每段 `cachePut` 后把该段 markdown append 到 `<dir>/partial.md`（幂等：按段计数重写而非追加，避免重试重复）；incomplete 时返回值加 `partialFile` 路径，note「部分结果可先看（非最终版）」；**不进 savedFiles**；成功时随 `cleanupSegmentDir` 删除。**测试 3 例**。**0.5–1 人日**。

#### 3.18 Office 本地直读（D4）

- **新增** `lib/office.js`：zip 中央目录解析（EOCD 0x06054b50 / CEN 0x02014b50 / LOC 0x04034b50；method 8 → `zlib.inflateRawSync`，method 0 直读）→
  - **docx**：`word/document.xml` 正则+栈解析 `w:p/w:r/w:t`（段落）、`w:pStyle` Heading1–3（标题级）、`w:tbl`（表格，含 gridSpan/vMerge → merges）、`a:blip r:embed`（图片经 rels 映射 media）；`w:sdt/txbx/SmartArt` 块**静默跳过并计数**；
  - **pptx**：`ppt/slides/slideN.xml` 按 `a:p` 逐页；
  - **xlsx**：`xl/sharedStrings.xml` + `xl/worksheets/sheet1.xml` 行列 → table 块。
- 路由：`recognize()` 对 kind word/ppt 且扩展名 docx/pptx 且 `cfg.officeLocalRead!==false` → 先 `extractOfficeLocal`（产出 `{engine:"office-text", channel:"LOCAL", markdown, text, pages?}`，note「本地直读零配额；文本框/图片内文字未含，需全量请 --vl」）；异常（OLE/加密/解析失败）→ 落回现有云端 vl 路径。**xlsx**：files.js `sniffKind` PK 头含 `xl/` → kind `"excel"`，仅本地（云端不支持），失败抛 `E_OFFICE_READ`。
- 提取文本量过低（扫描型 docx，<50 字符）→ note 建议走 `--vl`。
- **测试 ~15 例**：**用 ooxml.js 写入器现场生成 docx fixture**（含标题/表格/图片/嵌套表）→ 读取断言块还原；手工构造最小 pptx/xlsx；OLE 头/加密 zip/损坏 XML 回落或报错。**5–7 人日**。

## 7. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 段落合并误拼 | 中 | 保守句读 + paraMerge 开关 + golden |
